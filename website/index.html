核心能力

点歌之外的每一件事都做好了

不只是同步播放：从搜索到聊天、从权限到大屏，一个房间需要的它都有。

🎧

实时同步播放

基于 Socket.IO：播放状态、队列、进度、暂停、拖动和跳歌，全房间毫秒级同步，断线自动重连。

🔍

四平台聚合搜索

一次搜索网易云、QQ 音乐、酷狗、汽水四大曲库；房主授权登录音源，全房间共享高品质音源，凭据加密保存在服务端。

💬

房间聊天互动

文本、表情、回复、@ 提及、消息回应；FM 模式随机放歌，聊天区直接点歌，气氛不冷场。

🛡️

房主权限管理

6 位房间号、密码房间、锁定房间；管理员/贵宾角色、禁言踢人、点歌规则和音质设置，房主权杖在手。

📺

TV 大屏模式

浏览器访问 /tv/房间号，投上客厅大屏或投影；封面背景视觉效果跟随播放变化。

⚙️

AutoDJ 与本地曲库

队列低水位自动补歌、按歌曲/歌手去重；扫描本地音乐标签建立曲库，深夜没人点歌也不冷场。

快速开始

三行命令，开始营业

一台有 Docker 的服务器就够了。

bash — JukeboxRoom
$ git clone https://github.com/yuchen0x1/JukeboxRoom.git
$ cd JukeboxRoom
$ docker compose up -d --build

打开 http://服务器IP:4000 创建房间即可。 生产环境的安全配置见 README。
