## 📢 版本概述

本版修复多人房间的断线重连竞态、Windows 下服务端测试隔离失败，以及生产环境自更新缺少前端构建依赖的问题。自托管服务端最低运行版本现为 Node.js 24。

## ✨ 新增功能

- **重连会话保护**：连接超时后可重新建立尚未完成的 Socket.IO 连接；离开房间或切换房间后，旧重连请求不会覆盖当前会话。

## 🔧 改进与优化

- **自托管更新**：生产环境一键更新会安装客户端构建所需的 TypeScript 和 Vite 开发依赖。
- **运行时兼容**：服务端要求 Node.js 24 或更高版本。Node.js 20/22 不再是受支持运行环境；升级前请先更新 Node.js。

## 🐛 问题修复

- **Windows 测试隔离**：测试通过结构化文件读取子进程数据目录，不再因 TAP 对反斜杠路径转义而误报失败。
- **房间重连**：修复首次连接超时后的重试挂起，以及旧房间迟到响应覆盖已退出/新加入房间的问题。
- **生产一键更新**：修复 `NODE_ENV=production` 下 npm 省略前端构建依赖、导致更新后构建失败的问题。

## 🔒 安全与兼容性

- **运行环境**：服务端现在明确要求 Node.js 24+；请在升级自托管部署前完成运行时升级。
- **桌面签名**：仓库未配置 Windows 代码签名凭据，本版仍发布未签名 Windows 安装包和更新元数据以保持旧版更新提示；首次运行可能触发 SmartScreen，新安装不会启用后续应用内更新。

## 🔄 升级与数据迁移

- **兼容性**：自托管 Node.js 用户需先升级到 Node.js 24+；Docker 用户按原方式重建容器。
- **配置和数据**：本版不改变既有数据格式，继续保留部署者的数据目录与桌面用户数据。
- **回退方式**：自托管用户可重新部署上一版本资产；回退时仍需使用 Node.js 24+，除非手动回退依赖和代码至仍支持旧 Node 版本的历史版本。
